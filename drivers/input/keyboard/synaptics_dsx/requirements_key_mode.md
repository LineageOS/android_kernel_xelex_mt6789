# 按键模式需求规格书

## 1. 模式定义

- **触摸模式**：原有触摸功能，上报多点触控坐标。
- **按键模式**：将首个手指的滑动转换为方向键事件。
- **互斥关系**：两种模式通过同一个开关控制，**同一时间只能开启一种模式**。
  - 开关关闭 = 触摸模式（默认）
  - 开关开启 = 按键模式

## 2. 开关控制

- 通过 **sysfs 节点** 控制模式切换。
- 节点路径：
  - `/sys/bus/i2c/devices/xxxx/key_mode_enable`
  - `/sys/bus/i2c/devices/xxxx/key_x_threshold`
  - `/sys/bus/i2c/devices/xxxx/key_y_threshold`
- `key_mode_enable`：
  - `0`：触摸模式（默认）
  - `1`：按键模式

> 切换时无需特殊初始化，以当前手指下一次按下为起点开始检测。

## 3. 按键模式触发逻辑

### 3.1 生效对象
- 仅对 **第一个按下的手指** 生效。
- 按 tracking id / slot 最小值判定首个手指。
- 首个手指抬起后，按键模式状态立即复位。

### 3.2 触发方向（反向映射）

| 手指移动方向 | 触发按键 |
|---|---|
| `+X` 方向位移 ≥ 阈值 | `KEY_RIGHT` |
| `-X` 方向位移 ≥ 阈值 | `KEY_LEFT` |
| `+Y` 方向位移 ≥ 阈值 | `KEY_DOWN` |
| `-Y` 方向位移 ≥ 阈值 | `KEY_UP` |

> 采用正向映射，即手指向右滑触发右键。

### 3.3 方向锁定策略
- 一旦某个方向成功触发按键，**锁定当前轴向**：
  - 若首次触发的是 X 轴方向（KEY_LEFT 或 KEY_RIGHT），则后续只检测 X 轴位移，Y 轴位移忽略。
  - 若首次触发的是 Y 轴方向（KEY_UP 或 KEY_DOWN），则后续只检测 Y 轴位移，X 轴位移忽略。
- 轴向锁定持续到首个手指抬起后解除。

### 3.4 重复触发
- 锁定轴向后，手指继续在锁定轴方向滑动。
- 每当相对**最新起点**的位移再次超过阈值时，**重复触发同方向按键**。
- 每次触发后，将**当前位置更新为新起点**，重新累计位移。

### 3.5 复位条件
- 首个手指抬起时，立即复位：
  - 清除起点
  - 清除锁定轴向
  - 等待下一次手指按下重新开始检测

## 4. 可配置参数

通过 sysfs 节点提供以下配置：

| 参数节点 | 类型 | 说明 | 默认值 |
|---|---|---|---|
| `key_mode_enable` | int | `0`=触摸模式，`1`=按键模式 | `0` |
| `key_x_threshold` | int | X 轴触发阈值，单位：像素 | `80` |
| `key_y_threshold` | int | Y 轴触发阈值，单位：像素 | `80` |

## 5. 按键事件上报规范

每次触发按键时，按标准输入子系统方式上报一次完整的按下/释放事件：

```c
input_report_key(input_dev, KEY_LEFT, 1);   // press
input_sync(input_dev);
input_report_key(input_dev, KEY_LEFT, 0);   // release
input_sync(input_dev);
```

- 不需要保持长按状态。
- 不需要依赖 input 子系统的 auto-repeat。
- 手指抬起时，无需额外清理按键状态（每次触发已自带 release）。

## 6. 状态机

```
[IDLE]
  │ 首个手指按下
  ▼
[TRACKING] ──记录起点，累计 X/Y 位移──┐
  │                                  │
  ▼ 任一方向位移达阈值               │
[TRIGGER] ──上报按键，锁定轴向───────┤
  │ 更新起点为当前位置               │
  ▼                                  │
[LOCKED] ◄───────────────────────────┘
  │
  │ 锁定轴方向继续滑动并达阈值 → 重复触发按键，更新起点
  │ 非锁定轴方向滑动 → 忽略
  │ 手指抬起 → 复位
  ▼
[IDLE]
```

## 7. 边界场景处理

| 场景 | 处理 |
|---|---|
| 触发后立刻反向滑动 | 因轴向已锁定，同轴反向触发对应按键（如 +X 触发 KEY_LEFT，继续 -X 滑动则触发 KEY_RIGHT） |
| 锁定 X 轴后 Y 轴移动 | 忽略 |
| 多指同时按下 | 仅对首个手指生效 |
| 首个手指未抬起时切换开关 | 以开关切换后的状态为准；建议抬起后生效或立即复位 |
| 阈值动态修改 | 以最新阈值为准，下次检测生效 |

## 8. 兼容性

- 按键模式开关关闭时，原有触摸功能完全不变。
- 按键模式开启时，不上报触摸坐标，仅上报方向键事件。
- 多点触控下，仅首个手指参与按键模式检测，其他手指忽略。
