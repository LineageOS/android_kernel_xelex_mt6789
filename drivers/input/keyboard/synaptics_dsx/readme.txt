我现在需要在现有触摸模式下增加按键模式，具体要求和需求如下:                                                                                                                                                       │
1.以按下手指为起点，当X正方向移动一定的阈值转化成KEY_LEFT，当X反方向移动一定的阈值化成KEY_RIGHT,当传化成按键之后，开始重新计算移动量。如此反复直到手指抬起复位                                   │
2.以按下手指为起点，当Y正方向移动一定的阈值转化成KEY_DOWN，当X反方向移动一定的阈值化成KEY_UP,当传化成按键之后，开始重新计算移动量。如此反复直到手指抬起复位                                      │
3.需要方向锁定功能，一旦达到一个方向的按键转化，则锁死方向直到手指抬起                                                                                                                           │
4.阈值可以自定义修改，方便用户调整。                                                                                                                                                             │
5.兼容触摸模式和按键模式，按键模式可以通过开关开关，不影响原有触摸功能
6.由于支持多点触控，按键模式只针对第一个手指
